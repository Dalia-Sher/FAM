# מניעת הריון · טבלת שמ״פ

אפליקציית ווב למילוי טבלת מעקב לפי שיטת המודעות לפוריות (מניעת הריון), במקום למלא את ה־PDF ידנית.

## שימוש מהטלפון / מכל מקום

**גרסה מקוונת (GitHub Pages):**  
https://dalia-sher.github.io/FAM/

הנתונים נשמרים בדפדפן במכשיר שלך בלבד (לא בענן).

## הרצה מקומית

```bash
npm install
npm run dev
```

פתחי את הכתובת שמופיעה בטרמינל (בדרך כלל `http://localhost:5173`).  
באותה רשת Wi‑Fi אפשר גם מהטלפון דרך כתובת ה־Network של Vite.

## תכונות

- טבלה עברית RTL לימים 1–40 עם חום שחר, ריר, יום שיא, צוואר הרחם ועוד
- חישוב אוטומטי של יום בשבוע, ספירה אחרי יום השיא, וספירת שלב לוטאלי (ניתן לעריכה)
- הדגשה ויזואלית של ימים שסימנת כרלוונטיים לפוריות
- שמירה מקומית בדפדפן (`localStorage`), ייצוא/ייבוא גיבוי JSON, הדפסה / שמירה ל־PDF

**חשוב:** זה כלי תיעוד בלבד — לא ייעוץ רפואי.

הקובץ המקורי להתייחסות: `FAM_BirthControlChart.pdf`.
